HELPDESK V20 - RUSTDESK VINCULADO AO USUARIO

Novidade:
- Cada usuario cadastrado possui um campo ID RustDesk.
- Ao abrir chamado, o ID do usuario logado aparece automaticamente no campo ID RustDesk.
- O campo pode ser alterado manualmente quando necessario.
- Ao iniciar o primeiro acesso remoto, o ID usado e gravado no chamado e, se o nome do solicitante corresponder a um usuario cadastrado, o ID tambem e salvo no cadastro desse usuario.
- Nos proximos chamados desse usuario, o ID vinculado ja aparece automaticamente.
- O ID pode ser alterado no cadastro do usuario ou diretamente no chamado.
- IDs aceitos: somente numeros, de 6 a 20 digitos.

Fluxo:
1. Cadastre o usuario e, se ja souber, informe o ID RustDesk.
2. Caso nao informe, abra um chamado normalmente.
3. O ID vinculado ao usuario aparecera automaticamente.
4. No atendimento, confirme o acesso remoto.
5. O ID usado fica registrado no historico e vinculado ao usuario cadastrado quando houver correspondencia exata de nome.
