HELPDESK TI - V15

ALTERAÇÃO PRINCIPAL
- A primeira página agora é obrigatoriamente a tela de login.
- Nenhum operador acessa o formulário de chamados sem autenticação.
- Usuário com perfil operador entra diretamente na página de abertura de chamado.
- Administrador da Matriz entra diretamente no painel do TI.
- Operador vê sua identificação e unidade no topo e possui botão Sair.
- Operadores só podem abrir chamados na própria loja.
- Operadores só podem consultar chamados da própria loja.
- A Matriz mantém acesso aos chamados das duas unidades.

FLUXO
1. Abrir o Helpdesk.
2. Informar usuário e senha.
3. Perfil operador -> página "Abrir novo chamado".
4. Perfil admin -> painel do TI.

A base de dados continua sendo helpdesk.db e as contas da V14 são preservadas.


V16 - EXCLUSÃO DE USUÁRIOS
- O cadastro de usuários agora possui o botão 🗑️ Excluir.
- A exclusão é definitiva da conta, com confirmação.
- Os chamados já registrados não são apagados e continuam preservados no histórico.
- O usuário atualmente logado não pode ser excluído pela tela de gerenciamento.
